--------------------------------------------------------------------------
The cache check
--------------------------------------------------------------------------

Go replays a cached test result when the inputs have not changed, which
for a suite that stands up a cluster means the second invocation asserts
nothing and exits zero. An earlier attempt at this criterion produced one
real run of 542 seconds and four replays of 55, each reporting the first
one's duration back verbatim.

Every e2e, integration, interop and soak target now passes -count=1, and
the five runs above were checked for cache hits:

  $ grep -l "(cached)" consec-run*.log
  (no matches)

Five distinct durations is the other half of that evidence.
